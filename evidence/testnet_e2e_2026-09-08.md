What this proves

The real testnet run demonstrates:

miner discovery through the metagraph;
public miner endpoint registration;
signed Bittensor HTTP authentication;
validator-side private replay;
validator-side finding integrity checks;
stateful scoring;
duplicate detection;
zero reward for duplicate findings;
score aggregation;
interaction with on-chain weight submission/rate limiting.

A previous real testnet cycle successfully submitted weights on-chain (TimelockedWeightsCommitted).

Important scope distinction

The repository's 3-validator / 10-miner evidence is a local deterministic simulation.

It must not be presented as a real 3-validator / 10-miner testnet deployment.

This document records the separate real testnet end-to-end run with 1 validator and 1 registered miner.
