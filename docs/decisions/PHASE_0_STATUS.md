# Phase 0 — Research Status

Date: 2026-08-27

## Initial hypothesis

Agent Security Intelligence Network:
a Bittensor subnet where miners independently analyze autonomous-agent
security challenges and validators score their security decisions.

## New finding

The current hackathon landscape contains strong adjacent mechanisms,
especially Proven and TestForge, both using objective mutation-based
evaluation.

## Consequence

A generic security-classification subnet is not sufficient for a
top-tier submission.

## Revised hypothesis

Investigate an adversarial agent-security market in which validators
construct controlled agent environments and miners compete on their
ability to detect, prevent, or generate adversarial behavior.

## Status

NOT APPROVED.

This is a research hypothesis and must survive mechanism,
anti-gaming, scalability, and implementation analysis before adoption.
